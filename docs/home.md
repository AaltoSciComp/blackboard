# Home page
The *Home page* is used to view a list of available presentations, edit or view them, and create new ones. It is laid out in two columns: on the left, there are tools for creating new sessions and returning to sessions hidden from the list. On the right is a sortable and filterable list of public sessions, which you can join as a presenter or a viewer by clicking on the buttons. The ones with a viewer password set have a different icon and color in the view button.

## Creating new sessions
A new presentation needs at least a descriptive *name*, and a *presenter password*. You can optionally specify a viewer password, if you don't want your presentation to be easily accessible by anyone. You can hide your presentation from the home page listing, but in this case be sure to take note of the presentation id so you can resume editing it later.

### Important security note
Blackboard 2.0 is **not intended for creating or distributing any confidential information**. The password protection (without username) and optional hiding from the home page listing is only for making it harder for outsiders to view your presentation. It does not prevent brute-force attacks, or someone sharing the password for others.

## Viewing existing sessions
To view a session, click on its eye icon. If the session has a viewer password set, the browser will prompt for it before letting you in.

## Editing / viewing presentations by id
In case your presentation is hidden from the list, you can resume editing ("Edit presentation by id") or view it ("View presentation by id") using the presentation's unique id number.
